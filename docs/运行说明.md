# 项目运行说明（校园活动交流平台）

> 适用 Windows。本项目是前后端分离：**后端**（FastAPI，端口 8000）+ **前端**（Vue/Vite，端口 5173），需要**开两个终端窗口**，先起后端、再起前端。
>
> 命令里的路径按你 clone 到本地的目录改，假设仓库在 `D:\WebGIS实习项目`。

---

## 一、新电脑第一次跑（先装依赖，只需一次）

### 1. 后端 Python 依赖

```powershell
cd D:\WebGIS实习项目\backend
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 2. 前端 npm 依赖

```powershell
cd D:\WebGIS实习项目\frontend
npm install
```

---

## 二、日常启动（每次开发前）

### 终端 1 —— 启动后端

```powershell
cd D:\WebGIS实习项目\backend
.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000
```

看到类似这行就代表成功（这个窗口**要一直开着**，别关）：

```
Uvicorn running on http://127.0.0.1:8000
```

### 终端 2 —— 启动前端

```powershell
cd D:\WebGIS实习项目\frontend
npm run dev
```

看到类似这行就代表成功：

```
Local: http://localhost:5173
```

### 浏览器打开

**http://localhost:5173**

1. 点右上角「注册」创建账号 → 登录；
2. 「＋ 发布内容」发一条（可传图）→ 首页能看到；
3. 进详情评论 → 头像下拉里进「个人中心 / 我的发布」体验资料修改、改密、管理自己内容。

## 三、两个常用的辅助地址

| 地址 | 用途 |
|---|---|
| `http://127.0.0.1:8000/docs` | 后端接口在线文档，可逐个点“Try it out”测试接口 |
| `http://127.0.0.1:8000/` | 后端健康检查（返回 JSON） |

> 图片/头像都是存后端 `backend/uploads/` 目录、通过 `/uploads/xx` 访问的；开发时 Vite 已把 `/uploads` 代理到后端，前端不用额外配置。

## 三・可选：填充演示数据（让首页有内容可演示）

空库时首页是空的。想快速生成一批“AI 模拟数据”（5 个演示账号 + 15 条帖子 + 评论 + 占位图），执行：

```powershell
cd D:\WebGIS实习项目\backend
.venv\Scripts\python.exe -m app.seed
```

- 演示账号密码统一：`123456`（账号见脚本输出：`demo_wang` 王小明 等），登录即可看到首页内容；
- 脚本**可重复执行**：每次会先清掉上一批演示数据再重建，**不影响真实用户**发布的内容；
- 占位图自动生成在 `backend\uploads\demo_*.png`。

## 四、常见问题（先看这里）

| 现象 | 处理 |
|---|---|
| `python 不是内部或外部命令` | 没装 Python，或安装时没勾 “Add python.exe to PATH” |
| `npm 不是内部或外部命令` | 没装 Node.js（装 LTS 版），装完重开终端 |
| 后端报 `address already in use`（8000 被占） | 换端口：`--port 8010`，并同步改 [frontend/vite.config.js](frontend/vite.config.js) 里 proxy 的 target 端口 |
| 前端端口 5173 被占 | Vite 会自动换到 5174，看终端提示的 `Local:` 地址访问即可 |
| 页面能开但列表空 / 弹“网络连接失败” | 看**后端那个终端窗口**：还在不在、有没有报错 |
| 登录后提示“登录已过期” | 正常是后端重启过、Token 过期，重新登录即可 |
| 改了表结构/字段后报错或行为不对 | **删除 `backend\app.db`**，重启后端会自动重建新表（注意：会清空该库里的数据） |
| 图片传了看不到 | 先确认上传时返回了 `/uploads/...`；再确认后端窗口无报错 |
