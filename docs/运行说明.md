# 项目运行说明（校园活动交流平台）

> 适用 Windows。本项目为前后端分离：**后端**（FastAPI，端口 8000）+ **前端**（Vue3/Vite，端口 5173）。需要**开两个终端窗口**，先起后端、再起前端。
>
> 命令里假设仓库已 clone 在 `D:\WebGIS实习项目`，成员请先按 [git协作说明.md](git协作说明.md) 拉取最新的 `main`。

---

## 一、环境要求（一次性准备）

- **Python 3.10+**（后端）
- **Node.js 16+**（前端）
- 二者需已加入系统 PATH（终端能直接敲 `python`、`npm`）

---

## 二、新电脑首次安装（只需一次）

```powershell
cd D:\WebGIS实习项目\backend
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt

cd D:\WebGIS实习项目\frontend
npm install
```

> 每次 `git pull` 拉到新的前端依赖变化后，建议再执行一次 `npm install`。

---

## 三、日常启动（每次开发）

### 终端 1 —— 启动后端

```powershell
cd D:\WebGIS实习项目\backend
.venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8000
```

看到 `Uvicorn running on http://127.0.0.1:8000` 即成功，**这个窗口要一直开着**。

### 终端 2 —— 启动前端

```powershell
cd D:\WebGIS实习项目\frontend
npm run dev
```

看到 `Local: http://localhost:5173` 即成功（若 5173 被占，Vite 会自动换端口，看终端提示）。

### 浏览器打开

**http://localhost:5173** → 右上角「注册」建账号 → 登录后即可使用。

## 七、数据库说明

- 数据保存在 `backend/app.db`（SQLite），**首次启动后端会自动建表**；
- 启动时自动补列：models 里新增字段会自动 `ALTER TABLE` 补上，无需删库重建；
- 账号、帖子、图片路径、评论、头像都持久化，重启不丢；
- 想清空数据重来：停止后端 → 删除 `backend\app.db` → 重新启动即可（会重建空表）。

## 八、常见问题

| 现象 | 处理 |
|---|---|
| `python 不是内部或外部命令` / `npm 不是…` | 未安装或未加 PATH，装好后重开终端 |
| 后端报 `address already in use`（8000 被占） | 换端口 `--port 8010`，并同步改 `frontend/vite.config.js` 的 proxy target |
| 前端页面能开但列表空 / 弹"网络连接失败" | 看**后端那个终端**是否还在、有无报错 |
| 图片上传后刷新不见 | 确认上传成功（返回 `/uploads/…`）且后端在运行 |
| 改了表结构/新增字段后启动报错 | 自动补列应已处理；若仍报错，删除 `backend\app.db` 重建（会清空数据） |
| 注册登录总是被顶掉/登录过期 | 后端重启会令旧 Token 失效，重新登录即可 |
