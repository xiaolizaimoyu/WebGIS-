该仓库为WebGIS实习开发小组项目
项目概述
本项目为智慧校园GIS可视化平台，基于前后端分离架构开发，前端采用 Vue3 + Leaflet 地图可视化技术，后端采用 Python FastAPI + Geopandas 地理信息处理技术。项目面向校园数字化建设需求，以本校真实校园场景为载体，实现校园电子地图与影像地图双模式展示、地图基础操控、精准定位、校园路径导航、矢量点线面要素增删改查、校园图文标注等全套GIS基础功能。
本项目定位轻量化、易落地、可视化效果强，依托AI辅助开发与现有开源Demo完成搭建。项目最终可实现校园地理信息数字化管理、校园场景可视化展示，可用于校园导览、地物信息标注、校园空间数据编辑与保存，具备良好的展示效果与实习实践价值。
